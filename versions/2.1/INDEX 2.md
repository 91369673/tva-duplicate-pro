# tva Duplicate Pro - Version 2.1

**Veröffentlichungsdatum:** 2. März 2024

## Über diese Version

Version 2.1 ist die erste offiziell getrackte Version des tva Duplicate Pro Plugins. Es ermöglicht die einfache Duplizierung von Beiträgen, Seiten und WooCommerce-Produkten.

## Dateien in dieser Version

- **tva-duplicate-pro.php**: Hauptdatei des Plugins
- **assets/**: CSS, JS und Bilder (wenn vorhanden)
- **includes/**: PHP-Klassen und Funktionen (wenn vorhanden)
- **README.md**: Allgemeine Informationen für GitHub
- **readme.txt**: WordPress-Plugin-Repository Beschreibung
- **CHANGELOG.md**: Änderungsprotokoll
- **LICENSE**: Lizenzinformationen
- **CONTRIBUTING.md**: Informationen für Mitwirkende
- **dist/tva-duplicate-pro.zip**: Installationspaket für WordPress

## Funktionen

- One-Click-Duplizierung von Beiträgen, Seiten und WooCommerce-Produkten
- Erhält alle Metadaten während der Duplizierung
- Spezielle Behandlung für WooCommerce-Produkte (Bilder, Galerie, SKU)
- Erstellt automatisch eine Entwurfskopie zur Überprüfung

## Installation

1. Laden Sie die ZIP-Datei herunter
2. Gehen Sie in Ihrem WordPress-Admin-Bereich zu Plugins > Installieren > Plugin hochladen
3. Wählen Sie die heruntergeladene ZIP-Datei aus und klicken Sie auf "Jetzt installieren"
4. Aktivieren Sie das Plugin
5. Verwenden Sie den Link "Duplicate with tva.sg" unter jedem Beitrag/jeder Seite
