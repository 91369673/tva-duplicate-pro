# tva Duplicate Pro - Versionsverzeichnis

Dies ist das Hauptverzeichnis für alle Versionen des tva Duplicate Pro WordPress-Plugins.

## Verfügbare Versionen

- [Version 2.1](/versions/2.1/) - Erste getrackte Version (2. März 2024)

## Über das Plugin

Das tva Duplicate Pro Plugin ermöglicht die einfache Duplizierung von Beiträgen, Seiten und WooCommerce-Produkten mit nur einem Klick. Es ist ein nützliches Werkzeug für Content-Manager und Entwickler, die häufig bestehende Inhalte als Basis für neue Inhalte verwenden möchten.

## Installation der neuesten Version

1. Laden Sie die ZIP-Datei der neuesten Version herunter
2. Gehen Sie in Ihrem WordPress-Admin-Bereich zu Plugins > Installieren > Plugin hochladen
3. Wählen Sie die heruntergeladene ZIP-Datei aus und klicken Sie auf "Jetzt installieren"
4. Aktivieren Sie das Plugin
5. Verwenden Sie den Link "Duplicate with tva.sg" unter jedem Beitrag/jeder Seite
